**Learning outcome**
- Excel files (.xlsx, .xlsm, .xlam, etc.) aren't a single-blob. They're `zip` archives containing a bunch of XML files, per the Office Open XML (OOXML/ECMA-376) spec.
- `calamine` + `office_crypto` handle the password protected excel files.
- Index off because of 0/1 and header.
